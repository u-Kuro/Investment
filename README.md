# Investment Tracker

An Android application that tracks and analyzes stock and cryptocurrency investments using Yahoo Finance data.

## Features

- Price boundary calculations for investment decisions
- Daily percentage increase tracking
- Investment range status filtering
- Notification system for price changes and opportunities

## Technical Details

### Requirements

- Android SDK 24+ (Android 7.0+)
- Java 11
- Gradle 8.0+

## Building

1. Clone the repository
2. Open in Android Studio
3. Sync Gradle dependencies
4. Build and run
